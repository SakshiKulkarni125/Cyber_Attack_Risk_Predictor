# Cyber_Attack_Risk_Predictor

A machine-learning-based cybersecurity system that analyzes network traffic and predicts the **risk and type of cyberattack**.

The system combines **machine learning classification** and **anomaly detection** to identify suspicious network behavior and generate an attack risk score.

### 🎯 Features

* Cyberattack classification
* Attack risk prediction
* Anomaly detection
* Explainable AI predictions
* Risk monitoring dashboard
* Prediction history

### 🛠️ Technology Stack

* **Machine Learning:** Random Forest / XGBoost, Isolation Forest
* **Explainable AI:** SHAP
* **Backend:** Python, FastAPI
* **Frontend:** React
* **Database:** PostgreSQL

### 📊 Example Output

```text
Attack Risk: 87% — HIGH
Predicted Attack: DoS
Anomaly Score: 0.91
```
